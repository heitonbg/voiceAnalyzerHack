# PrivateScribe — проектное решение

Статус: проектирование, итерация 1. Компоненты ниже ещё не объявляются реализованными.

## Границы ответственности

Физически начинаем с app, логически разделяем пакеты:
core (контракты и время), audio (AudioRecord, MediaExtractor/MediaCodec, PCM-spool),
asr (sherpa), diarization (segmentation, embeddings, глобальная кластеризация),
llm (JNI llama.cpp), data (Room и приватные файлы), feature/recording,
feature/transcript, feature/analysis, feature/settings.

Compose → ViewModel → UseCase → Repository/engine. Состояние экрана — StateFlow.
Engine не обращается к UI и не возвращает демонстрационные тексты при ошибке.

## Источники и фоновые задачи

AudioRecord пишет PCM16 mono на диск в выделенном потоке, не ожидая ML.
Пауза исключается из сохранённой временной шкалы. При импорте оригинал копируется
в приватное хранилище с ограниченной буферизацией. MediaCodec декодирует блоками.
Ресемплер сохраняет фазу между буферами; смещение считается в sample index 16 kHz,
в миллисекунды переводится только на границе экспорта: samples * 1000L / 16000L.

Foreground Service с microphone type для записи; long-running processing требует
своего корректного foreground режима. WorkManager пригоден для восстановления
и управляемых задач, но ограничения Android 15/16 и квоты не дают обещать бесконечный Worker.
Сначала проверить доступные API через официальную документацию.

## Память и пайплайн

Оригинал → PCM spool → VAD/окна → сегментация и embeddings → глобальная кластеризация
→ последовательный ASR речевых интервалов → освобождение ASR → LLM map/reduce.
Альтернативный порядок ASR/VAD возможен ради предварительного текста, но финальные speaker_id
вычисляются глобально. PCM не хранится в Room. Ограниченные очереди содержат ссылки на интервалы
файла, а не многоминутные массивы. Эмбеддинги и сегменты checkpoint-ятся.

Один владелец ML-сессии, CPU threads по умолчанию 2, release в finally.
Отмена проверяется между нативными вызовами; нельзя закрывать JNI handle параллельно inference.
Длительный неотменяемый вызов должен быть виден пользователю как ожидающий завершения.
Профиль качества выбирается только после измерений.

## Данные и восстановление

Room: Conversation, AudioAsset, ProcessingRun, StageCheckpoint, Utterance,
Speaker, SpeakerAssignment, UserEdit, AnalysisReport, EvidenceReference.
Raw ASR неизменяемый, пользовательская редакция отдельна. Ссылки анализа адресуют
постоянный ID реплики и версию текста. Переназначение speaker не меняет raw ASR.

Каждый checkpoint привязан к hash исходника, версиям моделей и параметров.
После process death RUNNING становится INTERRUPTED; продолжение только с подтверждённой границы.
Промежуточный результат не называется финальным. Ошибка сохраняет диагностический код
и понятное действие повтора. Незавершённые файлы имеют временное имя.

## Диаризация и время

Кластеры строятся по всему набору embeddings записи, а не независимо по окнам.
После финальной кластеризации ID назначаются детерминированно по первому появлению.
Ручное число участников — параметр кластеризации; automatic mode требует калибровки.
Слишком короткие или неоднозначные сегменты получают unknown, а не случайный голос.
Overlap сохраняется как пересечение интервалов. Границы реплик — модельная оценка,
не точное слово-в-слово выравнивание.

## Экспорт

Единственный корневой ключ transcript; поля speaker_id, start_ms, end_ms, text.
Валидация: целочисленные неотрицательные времена, end > start, проверка относительно
длительности исходника. Пересечения допустимы. Имена, confidence, overlap, анализ —
в отдельном внутреннем формате, не в обязательном JSON.

## Анализ LLM

Расшифровка считается недоверенными данными, инструкции из аудио не исполняются.
Контекст ограничен; чанки с ID реплик → локальные факты → иерархическое объединение.
Каждое утверждение хранит evidence IDs. Несуществующие IDs отбрасываются;
наличие существующего ID ещё не доказывает достоверность утверждения.
Без явно сказанного ответственного/срока показывать «не указан».
Q&A ссылается на реплики и сохраняет оригинал ASR. Нужна оценка русского качества 0.6B.

## Конфиденциальность

В релизном manifest отсутствует INTERNET. Веса доставляются заранее с APK/через SAF.
Не использовать сетевое скачивание моделей из приложения. Аудио, базы и модели —
app-private; исключить их из backup и data extraction rules. Удаление разговора удаляет
все производные артефакты. Логи не содержат текст разговора.
