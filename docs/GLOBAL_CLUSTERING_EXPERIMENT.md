# Эксперимент глобальной кластеризации

Экспериментальный код находится в `ExperimentalGlobalClustering`; production v25 не вызывает его. На вход подаются сохранённые VoiceTurn с TitaNet embeddings, временами и признаком overlap. Исследуются адаптивная average-link agglomeration и spectral clustering с eigengap. Оба варианта выбирают число кластеров без известного числа участников, нормализуют векторы, исключают overlap из построения профилей и оставляют сомнительные фрагменты unknown. Для ограничения квадратичных матриц используется до 64 равномерно распределённых по записи опорных эмбеддингов.

Это исследовательские реализации, а не подтверждённая замена v25. Их ограничения: subsampling может пропустить редкого участника; пороги и eigengap требуют независимой проверки; отсутствуют ограничения cannot-link для одновременных голосов; нет экспериментального пути импорта с атомарной публикацией готовой расшифровки. Алгоритмы нельзя считать готовыми для production.
