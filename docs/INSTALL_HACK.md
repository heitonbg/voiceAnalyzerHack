# Установка и использование PrivateScribe

Нужны Android 10 (API 29) или новее, ARM64 либо x86_64, ориентир — 4 ГБ RAM и как минимум 2,5 ГБ свободного места. ARM runtime на физическом устройстве пока не проверен. Debug APK локальной сборки: `app/build/outputs/apk/debug/app-debug.apk`; публичная ссылка пока отсутствует.

Установите APK через Android Studio или `adb install -r app-debug.apk`. Все 12 файлов моделей включены в APK; при первом запуске приложение копирует их в приватное хранилище и проверяет SHA-256 без сети. Дождитесь завершения подготовки. Нажмите «Загрузить аудио», выберите локальный файл и дождитесь завершения обработки. Откройте запись в истории, проверьте участников и текст. Кнопки экспорта позволяют сохранить JSON или поделиться PDF. ИИ-анализ выполняется локальной Qwen.

Android может попросить разрешить установку из выбранного источника. APK подписан debug-ключом и предназначен для проверки. Точность разделения говорящих и границ фраз не гарантируется.

Сборка и тесты: [testing.md](testing.md). Архитектура и ограничения: [ARCHITECTURE.md](ARCHITECTURE.md), [MODEL_COMPATIBILITY.md](MODEL_COMPATIBILITY.md), [README](../README.md).
