Реализация:

- Не более 32 s float PCM в диаризации; весь 15-минутный PCM не загружается в память.
- Native Pyannote/TitaNet segmentation локального окна, затем настоящие embeddings чистых голосов.
- Единая глобальная кластеризация embeddings всей записи; стабильное именование по первому появлению.
- До 64 промежуточных centroid groups с ограниченной памятью; сомнительные assignments → speaker_unknown.
- Счётчик участников может быть задан отдельно; автоматический порог пока предварительный.
- Перекрытие голосов помечается overlap=true и unknown: нет обещания separation двух одновременных текстов.
- AtomicFile checkpoint метаданных/embeddings после каждого блока.
- Диаризация закрывается до загрузки финального ASR. LLM пока не загружается приложением.
- Room version 2: sourcePass и overlap, явная migration 1→2 вместо destructive reset.
  Смена параметров архивирует прежний финальный проход; IDs включают конфигурацию.
- Удаление разговора удаляет связанные PCM/checkpoint/embedding файлы.

Ограничения: нет DER, независимой русской многоголосой разметки и physical ARM испытания.
Global centroid clustering не эквивалентен встроенному whole-file кластеризатору sherpa:
нельзя переносить его threshold/benchmark напрямую. Нужна отдельная калибровка на русских разговорах.
Ограничения overlaps и неопределённости должны оставаться видимыми в UI и документации.
